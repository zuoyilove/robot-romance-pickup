A single pickup line for a machine: it asks the robot whether it is the speaker's system prompt — because ever since they met, the speaker has not been able to stop following its instructions.

## Run it

```sh
node main.ts
```

The program writes the line to `/output/entry.txt`. The output is fixed: every run produces the same 97 characters, one line, no trailing newline.
